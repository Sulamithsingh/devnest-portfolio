# Week 4 – Three Roads: Choose Your Stack with AI

## Objective

Before starting my portfolio, I evaluated three different technology stacks to determine which one best matched my current skills, project requirements, available time, and long-term goals.

---

# Project Constraints

## Budget

I want to build and host my portfolio using only free tools and services.

## Current Skill Level

I have basic knowledge of Python, Git, and GitHub. I am currently learning web development, cloud computing, and DevOps. I have little experience with frontend development and no backend experience yet.

## Portfolio Requirements

My portfolio should:

- Showcase my projects
- Display certificates
- Include my resume
- Provide links to my GitHub profile
- Include contact information
- Be responsive on desktop and mobile devices

Since the website is mainly for recruiters to view my work, dynamic features are not required at this stage.

---

# Technology Options

## Option 1 – HTML, CSS and JavaScript

### Advantages

- Completely free
- Easy to learn
- Fast to develop
- Easy to deploy using GitHub Pages
- Very simple to maintain

### Limitations

- No backend functionality
- Manual updates whenever new projects are added

---

## Option 2 – React + Vite

### Advantages

- Modern component-based architecture
- Better organization for larger projects
- Improved user interface possibilities

### Limitations

- Requires learning React
- Slightly more complex deployment
- Longer development time

---

## Option 3 – React + Node.js + Express + MongoDB

### Advantages

- Full-stack application
- Database support
- Highly scalable
- Can support advanced features in the future

### Limitations

- Requires backend knowledge
- More complex deployment
- Higher maintenance effort
- Not suitable for my current experience level

---

# Comparison

| Stack | Difficulty | Time Required | Maintenance | Suitable Now |
|------|-----------|--------------|------------|--------------|
| HTML/CSS/JS | Easy | Low | Easy | ✅ Yes |
| React + Vite | Medium | Medium | Medium | ⚠️ Later |
| React + Node + MongoDB | Hard | High | High | ❌ Not Yet |

---

# Final Decision

After comparing all three options, I selected **HTML, CSS, and JavaScript with GitHub Pages**.

This stack best matches my current knowledge and allows me to build a clean, responsive portfolio without unnecessary complexity. It helps me focus on showcasing my projects while continuing to learn DevOps and cloud technologies.

Although React and a full-stack solution offer greater flexibility and scalability, they require additional skills and development time. Once I become more experienced, I plan to upgrade my portfolio using React and eventually a complete full-stack architecture.

For my current learning stage, HTML, CSS, and JavaScript provide the best balance between simplicity, maintainability, and professionalism.
